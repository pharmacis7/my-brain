PrimeChecker.java
public class PrimeChecker {
    public static boolean isPrime(int n) {
        // Step 2: numbers <= 1 are not prime
        if (n <= 1) return false;
        
        // Step 3: 2 is the only even prime
        if (n == 2) return true;
        
        // Step 4 & 5: Check divisors up to sqrt(n)
        for (int i = 2; i * i <= n; i++) {
            if (n % i == 0) {
                return false; // Divisible
            }
        }
        
        // Step 6: No divisors found -> Prime
        return true;
    }
}

Why only check up to \(\sqrt{n}\)?

Every composite number n can be expressed as a product of two factors: n = a × b.

If both a and b were greater than √n, then their product a × b would be strictly greater than √n × √n = n, which is impossible.

Example for n = 36:
√36 = 6.
Factors: (2, 18), (3, 12), (4, 9), (6, 6).
Notice that one factor is always ≤ 6 and the other is ≥ 6. Thus, checking divisors beyond 6 is redundant!
